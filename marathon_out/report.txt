HOW TO READ THIS
------------------------------------------------------------------------------
 * A p-value can never go below its floor 1/(n+1). 'At the floor' means no null has
   matched the real data yet, so more replicates are needed to see how extreme it is.
 * Beating the SHUFFLE null only shows the symbol order is not random. Beating the
   DOUBLET null means structure beyond adjacent-pair habits, which is far more interesting.
 * Word tests and held-out tests are not what the search optimises, so they are
   independent checks. A real solution should pass them as well.
 * Compare the Dorabella with the CONTROLS. A real English message under this model
   should look like them: high z, a readable decode, held-out p at the floor.
 * DEEP homophonic keys can make gibberish score well. Only its p-value counts, never the raw score.
